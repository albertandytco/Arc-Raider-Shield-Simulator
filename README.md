# 🛡️ Simulador de Escudos - Arc Raiders

Este é um simulador de dano em tempo real para o jogo **Arc Raiders**, projetado para ajudar jogadores a entenderem como os diferentes escudos mitigam o dano recebido.

## 🚀 Funcionalidades

- **Simulação de Disparos:** Seleção de diversas armas com danos específicos.
- **Visualização de Mitigação:** Três tipos de escudos (Leve, Médio e Pesado) com diferentes níveis de proteção.
- **Barras de Status Precisas:** Divisores visuais a cada 10 unidades para melhor visualização tática.
- **Cálculo em Tempo Real:** Feedback imediato de dano no escudo vs. dano na vida.
- **Interface Moderna:** Design responsivo e temático construído com Shadcn UI e Tailwind.

## 🛠️ Tecnologias Utilizadas

- **Next.js 15** (App Router)
- **React 19**
- **Tailwind CSS**
- **Shadcn UI**
- **TypeScript**
- **Lucide React** (Ícones)
- **Firebase Genkit** (IA)

## 📝 Lógica de Dano

O simulador segue a regra de que o escudo mitiga o dano na vida: 
`Dano na vida = Dano x (1 - Mitigação)`
